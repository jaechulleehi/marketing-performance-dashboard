# 조인 규칙 (Join Rules)

channel(기준) 과 appsflyer 를 합치는 규칙.

## 입력 폴더 구조

```
raw/channel/YYYY-MM-DD.csv      (일별)
raw/appsflyer/YYYY-MM-DD.csv    (일별)
raw/braze/...                   (CRM, 별도 grain — 이 조인의 대상 아님)
```
- 파일 발견: `raw/<source>/*.csv` glob. 날짜는 파일명 = 파일 내 `일` 컬럼.
- 인코딩 UTF-8(BOM 허용, `utf-8-sig`).
- **Braze 제외 이유**: 유저/거래 단위 + 월/분기/스냅샷 주기라 `날짜×채널×캠페인×그룹×소재`
  grain으로 조인 불가. CRM 분석은 별도 파이프라인에서 다룬다.

## 조인 키

```
일 · 채널 · 캠페인 · 그룹 · 소재
```
- `채널`은 appsflyer `미디어소스`를 매핑 후 사용 ([naming-convention.md](naming-convention.md) §3).
- 조인 방식: **channel LEFT JOIN appsflyer** (channel 기준, 노출/비용 보존).

## 컬럼 충돌 처리

양쪽에 같은 이름(클릭·회원가입·구매·구매매출)이 있으므로:
- channel 쪽: 원래 이름 유지 (`구매`, `구매매출` …)
- appsflyer 쪽: `_앱스플라이어` 접미사 (`구매_앱스플라이어` …)
- 비교 별칭: `_채널` 접미사 컬럼 병행 생성
- 파생: `구매차이 = 구매 − 구매_앱스플라이어` (어트리뷰션 갭)

## 미스매치 처리

| 상황 | 처리 |
|---|---|
| channel에만 있는 행 | 유지 (앱스플라이어 컬럼 NULL). 노출/비용은 항상 channel이 정답 |
| appsflyer에만 있는 행 | LEFT JOIN이므로 자동 제외. 단, **개수를 리포트에 명시** (어트리뷰션 누락 신호) |
| 채널 매핑 실패한 미디어소스 | 원본값 유지 + "미매핑" 경고. 추측 금지 |

## 중복(재업로드) 처리 🔧

기본 정책: **같은 (일 + 조인키) 중복 시 마지막(최신 mtime) 파일 우선**.
- 같은 날짜 파일을 다시 올리면 누적되지 않고 덮어쓰기 효과.
- 구현 권장: 로드 후 `drop_duplicates(subset=조인키, keep="last")`.

> 🔧 "누적이 맞다"면 정책 변경. 단, 누적 시 같은 날 이중 집계 위험을 반드시 안내.

## 데이터 품질 검증 (로드 시 체크)

- [ ] 필수 컬럼 존재 여부
- [ ] 날짜 파싱 가능 여부
- [ ] 음수 노출/클릭/비용 없음
- [ ] 조인키 중복 없음(중복 시 §중복 처리 적용 + 카운트 리포트)
- [ ] 비용>0 인데 노출=0 같은 모순 행 플래그
- [ ] 기대 채널(구글·메타·네이버) 누락 여부 → "불완전한 하루" 경고

검증 실패는 조용히 넘기지 말고 리포트 상단에 명시한다.
