# 데이터 사전 (Data Dictionary)

매일 업로드되는 두 소스의 모든 컬럼 정의. **타입·단위·출처**가 핵심.

## 파일 종류

| 파일 패턴 | 소스 | 의미 |
|---|---|---|
| `YYYY-MM-DD_channel.csv` | 광고 채널(매체) 리포트 | 매체가 청구·집계한 노출/클릭/비용 + 자가보고 전환 |
| `YYYY-MM-DD_appsflyer*.csv` | AppsFlyer (MMP) | 어트리뷰션 기반 클릭/전환/매출 |

## channel.csv 컬럼

| 컬럼 | 타입 | 단위 | 설명 | 비고 |
|---|---|---|---|---|
| 일 | date | YYYY-MM-DD | 집행 일자 | 조인 키 |
| 채널 | str | - | 구글 / 메타 / 네이버 | 조인 키 (매핑 필요) |
| 채널분류 | str | - | 외부 / 자체 | 외부=구글·메타, 자체=네이버 |
| 캠페인 | str | - | 캠페인명 | 조인 키. naming 규칙 적용 |
| 캠페인목적 | str | - | 플러스가입·첫구매·재구매 등 | channel.csv에만 존재 |
| 그룹 | str | - | 타겟 그룹(논타겟·유사타겟 등) | 조인 키 |
| 소재 | str | - | 크리에이티브명 | 조인 키. naming 규칙 적용 |
| 노출 | int | 회 | Impressions | **채널만 보유** |
| 클릭 | int | 회 | Clicks (매체 집계) | appsflyer에도 별도 존재 |
| 비용 | int | KRW | 광고비 | **채널만 보유 · 비용의 권위 출처** |
| 회원가입 | int | 건 | 매체 자가보고 가입 | appsflyer와 값 다름 |
| 구매 | int | 건 | 매체 자가보고 구매 | appsflyer와 값 다름 |
| 구매매출 | int | KRW | 매체 자가보고 매출 | appsflyer와 값 다름 |

## appsflyer.csv 컬럼

| 컬럼 | 타입 | 단위 | 설명 | 비고 |
|---|---|---|---|---|
| 일 | date | YYYY-MM-DD | 집행 일자 | 조인 키 |
| 미디어소스 | str | - | googleadwords_int / Facebook Ads / naver_search | → 채널로 매핑 |
| 캠페인 | str | - | 캠페인명 | 조인 키 |
| 그룹 | str | - | 타겟 그룹 | 조인 키 |
| 소재 | str | - | 크리에이티브명 | 조인 키 |
| 클릭 | int | 회 | 어트리뷰션 클릭 | 매체 클릭과 다름 |
| 회원가입 | int | 건 | 어트리뷰션 가입 | **전환의 권위 출처(기본값)** |
| 구매 | int | 건 | 어트리뷰션 구매 | **전환의 권위 출처(기본값)** |
| 구매매출 | int | KRW | 어트리뷰션 매출 | **매출의 권위 출처(기본값)** |

## 출처별 권위 요약 (Source of Truth)

| 지표 | 권위 출처 | 이유 |
|---|---|---|
| 노출 · 비용 | channel | 매체 청구 기준이 회계상 정답 |
| 클릭 | channel (기본) | 매체 집계 클릭. AF 클릭은 어트리뷰션 비교용 |
| 회원가입 · 구매 · 구매매출 | **AppsFlyer** 🔧 | MMP가 중복 어트리뷰션 제거·cross-channel 정합 |

> 🔧 전환/매출 권위 출처는 확정 필요. 현재 대시보드 초안은 channel 전환을 기본 표시 중이며,
> AppsFlyer로 확정하면 대시보드도 맞춘다. 상세: [metrics-definitions.md](metrics-definitions.md)

## 단위·형식 규칙

- 모든 금액 = 원(KRW) 정수. 천/백만 환산 금지.
- 0 나눗셈은 NULL 처리 (지표 정의 참조).
- 인코딩 UTF-8, 헤더 1행, 빈 줄 무시.
