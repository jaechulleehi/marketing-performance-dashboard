# 네이밍 컨벤션

소재명·캠페인명을 분해해 **파생 컬럼**을 자동 생성하기 위한 규칙.
아래 토큰 표는 현재 데이터에서 역추출한 실제 값이며, 신규 값 추가 시 이 문서를 먼저 갱신한다.

## 1. 소재(크리에이티브) 네이밍

형식:
```
{타입}_{카테고리}_{시즌}[_{AB}]_{버전}
예) VID_플러스멤버십_겨울_A_v1
   CRS_신상품_겨울_v1        ← AB 토큰 없음
```

| 토큰 | 위치 | 가능한 값(현재) | 파생 컬럼 |
|---|---|---|---|
| 타입 | 첫 토큰 | `VID`(영상) `IMG`(이미지) `CRS`(캐러셀) `TXT`(텍스트/검색) | `소재타입` |
| 카테고리 | 2번째 | 플러스멤버십·적립혜택·할인쿠폰·특가·배송혜택·신상품 | `카테고리` |
| 시즌 | 3번째 | 겨울 | `시즌` |
| AB | 끝-1 (선택) | `A` `B` 또는 **없음** | `AB변형`(A/B/없음→`단일`), `AB여부`(bool) |
| 버전 | 마지막 | `v1` `v2` | `버전` |

### ⚠️ 핵심 주의: AB 토큰은 선택적
- `..._A_v1`, `..._B_v1` → AB 테스트 소재
- `..._v1` (A/B 없음) → 단일 소재
- 따라서 **뒤에서부터 파싱**한다: 마지막=버전, 그 앞이 `A|B`면 AB변형, 아니면 AB 없음.

### 파싱 규칙(의사코드)
```
parts = 소재.split("_")
소재타입 = parts[0]
버전     = parts[-1]                 # v1, v2 ...
if parts[-2] in ("A","B"):
    AB변형 = parts[-2]; AB여부 = True
    시즌  = parts[-3]; 카테고리 = "_".join(parts[1:-3])
else:
    AB변형 = "단일"; AB여부 = False
    시즌  = parts[-2]; 카테고리 = "_".join(parts[1:-2])
```

## 2. 캠페인 네이밍

형식:
```
{채널코드}_CMP_{번호}_{목적}
예) GGL_CMP_01_플러스가입
```

| 토큰 | 값(현재) | 파생 컬럼 |
|---|---|---|
| 채널코드 | `GGL`(구글) `META`(메타) `NVR`(네이버) | `채널코드` |
| 번호 | 01·02·03 | `캠페인번호` |
| 목적 | 플러스가입·리타겟팅·첫구매·신규유저·룩얼라이크·재구매·브랜드KW·일반KW | `캠페인목적_파생` |

> 참고: channel.csv에는 `캠페인목적` 컬럼이 별도로 있으므로 교차검증 가능.

## 3. 채널 표기 매핑

| channel.csv | appsflyer.csv | 채널코드 |
|---|---|---|
| 구글 | googleadwords_int | GGL |
| 메타 | Facebook Ads | META |
| 네이버 | naver_search | NVR |

→ `data_pipeline.py`의 `MEDIA_SOURCE_TO_CHANNEL`과 동기화. 신규 채널은 여기 + 코드 동시 추가.

## 4. 그룹(타겟) 값

`논타겟` `유사타겟`(룩얼라이크) `리마케팅` `VIP` `윈백` — 자유 추가 가능, 의미는 [glossary.md](glossary.md).

## 신규 패턴 정책
규칙에 안 맞는 소재/캠페인명이 들어오면 **추측 파싱 금지**. 리포트에 "미분류" 표시 후 사용자에게 규칙 확장 확인.
