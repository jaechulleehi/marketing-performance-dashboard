# 용어집 (Glossary)

## 데이터 소스
- **채널 데이터**: 광고 매체(구글·메타·네이버)가 제공하는 집행 리포트. 노출·클릭·비용의 권위 출처.
- **AppsFlyer / MMP**: Mobile Measurement Partner. 어트리뷰션으로 전환을 매체에 귀속. 전환·매출의 권위 출처(기본값).
- **어트리뷰션 갭**: 매체 자가보고 전환과 MMP 전환의 차이. 매체 과대보고 진단 지표.

## 채널 분류
- **외부**: 외부 매체 광고 (구글, 메타).
- **자체**: 자사 채널/검색 (네이버).

## 타겟 그룹
- **논타겟**: 타게팅 없는 광범위 노출.
- **유사타겟 / 룩얼라이크(Lookalike)**: 기존 고객과 유사한 신규 잠재고객.
- **리마케팅 / 리타겟팅**: 방문·이탈 사용자 재유입.
- **VIP**: 고가치 기존 고객.
- **윈백(Winback)**: 이탈/휴면 고객 재활성화.

## 캠페인 목적
- **플러스가입**: 멤버십(플러스) 가입 유도.
- **첫구매 / 신규유저**: 신규 고객 첫 전환.
- **재구매**: 기존 고객 반복 구매.
- **브랜드KW / 일반KW**: 검색 광고 키워드 유형(브랜드명 vs 일반 키워드).

## 소재 타입
- **VID**: 영상 / **IMG**: 단일 이미지 / **CRS**: 캐러셀(다중 이미지) / **TXT**: 텍스트·검색 광고.

## 지표 약어
- **CTR**: 클릭률 / **CPC**: 클릭당비용 / **CPM**: 1000노출당비용
- **CVR**: 전환율 / **CPA**: 구매(획득)당비용 / **ROAS**: 광고비대비매출 / **AOV**: 객단가
- **WoW / MoM**: 전주/전월 대비.
