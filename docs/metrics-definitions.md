# 지표 정의 + Source of Truth + 판단 임계값

분석 시 **이 산식만** 사용한다. 즉흥 계산 금지.

## 지표 산식

| 지표 | 산식 | 단위 | 출처 |
|---|---|---|---|
| CTR (클릭률) | 클릭 ÷ 노출 | % | channel |
| CPC (클릭당비용) | 비용 ÷ 클릭 | KRW | channel |
| CPM (1000노출당비용) | 비용 ÷ 노출 × 1000 | KRW | channel |
| CVR (구매전환율) | 구매 ÷ 클릭 | % | 분자=권위 전환출처, 분모=channel 클릭 |
| 가입전환율 | 회원가입 ÷ 클릭 | % | 동일 |
| CPA (구매당비용) | 비용 ÷ 구매 | KRW | 비용=channel, 구매=권위 전환출처 |
| 가입당비용 | 비용 ÷ 회원가입 | KRW | 동일 |
| ROAS | 구매매출 ÷ 비용 | 배수 | 매출=권위 출처, 비용=channel |
| AOV (객단가) | 구매매출 ÷ 구매 | KRW | 권위 전환출처 |

> 0 나눗셈은 모두 NULL. 합산 지표는 "합의 비율"로 계산(비율의 평균 금지).
> 예: 전체 CTR = Σ클릭 ÷ Σ노출 (행별 CTR 평균 ❌).

## Source of Truth (지표 충돌 해소) 🔧

같은 이름의 지표가 channel·appsflyer 양쪽에 있을 때 어느 값을 쓸지:

| 지표 | 권위 출처(기본값) | 근거 |
|---|---|---|
| 노출 · 비용 | **channel** | 매체 청구액이 회계 기준 |
| 클릭 | **channel** | 매체 집계 클릭 |
| 회원가입 · 구매 · 구매매출 | **AppsFlyer** | MMP 어트리뷰션이 중복 제거·cross-channel 정합 |

**어트리뷰션 갭** = channel 자가보고 전환 − AppsFlyer 전환. 두 값의 차이는 버리지 말고
`구매차이` 컬럼으로 추적(매체 과대보고 진단용).

> 🔧 **확정 필요**: 위는 업계 표준 기본값. "전환·매출=AppsFlyer"가 맞으면 그대로,
> "channel 기준"으로 가려면 여기와 대시보드를 함께 변경. 확정 전까지 대시보드는
> channel 전환을 기본 표시하되 어트리뷰션 비교 탭에서 양쪽을 보여준다.

## 판단 임계값 (인사이트 작성 기준) 🔧

아래는 초기 가이드값. 실제 목표에 맞게 조정.

| 지표 | 양호 | 주의 | 경고 |
|---|---|---|---|
| ROAS | ≥ 4.0 | 2.0 ~ 4.0 | < 2.0 |
| CTR | ≥ 2.0% | 1.0 ~ 2.0% | < 1.0% |
| CPA | ≤ 5,000 | 5,000 ~ 10,000 | > 10,000 |

> 🔧 목표 ROAS·허용 CPA는 비즈니스 목표값으로 교체 필요.

## 분석 컨벤션
- 통화: KRW, 타임존: KST.
- 기간 비교: WoW(전주 동요일 대비), MoM(전월 대비). 비교 시 일수 정규화.
- 세그먼트 우선순위: 채널 → 캠페인목적 → 소재타입 → AB변형.
- 인사이트 출력: **요약 3줄 + 근거 표 + 액션 항목**.
